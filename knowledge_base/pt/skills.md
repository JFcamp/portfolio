# Competências Técnicas

Pedro tem experiência prática em toda a stack de machine learning e IA:
programação, dados, ML clássico, deep learning, visão computacional, PLN, LLMs
e RAG, MLOps, nuvem, engenharia de backend, segurança e os fundamentos
matemáticos. A lista detalhada abaixo reflete as ferramentas e temas com que
ele trabalha.

## Linguagens de Programação
Python (linguagem principal para IA, ML, automações e análise de dados), SQL,
Bash.

## Bancos de Dados e Armazenamento
SQL, MySQL, PostgreSQL, SQLite, bancos de dados relacionais (tabelas,
relacionamentos, chaves, índices, normalização), bancos NoSQL, MongoDB, data
warehousing, data lake.

## Bancos Vetoriais e Busca Semântica
Bancos vetoriais, FAISS, Pinecone, ChromaDB, pgvector, embeddings, similaridade
de cosseno, busca semântica (semantic search), re-ranking, chunking.

## Ciência e Análise de Dados
NumPy, Pandas, Matplotlib, análise exploratória de dados (EDA), limpeza de
dados (data cleaning), pré-processamento de dados, engenharia de atributos
(feature engineering), seleção de atributos (feature selection), ETL, data
pipelines, Apache Airflow, Apache Spark.

## Machine Learning
Machine learning, aprendizado supervisionado, aprendizado não supervisionado,
classificação, regressão, clustering, Scikit-learn, train/test split,
cross-validation, overfitting e underfitting, ajuste de hiperparâmetros
(hyperparameter tuning), grid search, random search.

## Métricas de Avaliação de Modelos
Métricas de avaliação, accuracy, precision, recall, F1-score, ROC-AUC, MAE,
MSE, RMSE.

## Deep Learning
Deep learning, PyTorch, TensorFlow, Keras, redes neurais artificiais,
backpropagation, gradient descent, CNNs (redes neurais convolucionais),
Transformers, attention, transfer learning, fine-tuning.

## Visão Computacional
Visão computacional, OpenCV, YOLO, segmentação de imagens, detecção de objetos
(object detection), classificação de imagens (image classification), image
augmentation, OCR.

## PLN e Grandes Modelos de Linguagem
Processamento de linguagem natural (PLN/NLP), tokenização, embeddings, LLMs,
engenharia de prompts (prompt engineering), system prompts, RAG (Geração
Aumentada por Recuperação), busca semântica, re-ranking, LangChain, LlamaIndex,
Hugging Face.

## APIs de LLMs e Agentes de IA
APIs de LLMs, OpenAI API, Anthropic Claude API, Google Gemini API, agentes de
IA, tool calling, function calling, gestão de contexto (context management),
guardrails para IA, avaliação de LLMs, detecção de alucinações (hallucination
detection).

## Backend e APIs
FastAPI, Flask, APIs REST, JSON, HTTP, WebSockets.

## Controle de Versão e Colaboração
Git, GitHub, branches e pull requests.

## DevOps, Containers e Nuvem
Docker, Docker Compose, Linux, Bash, cloud computing, AWS, Azure, Google Cloud,
AWS S3, AWS EC2, AWS SageMaker, Azure Machine Learning, GPU computing, CUDA,
Kubernetes.

## MLOps
MLOps, deploy de modelos (model deployment), model serving, monitoramento de
modelos (model monitoring), data drift, model drift, MLflow, CI/CD, GitHub
Actions, experiment tracking, reprodutibilidade.

## Automação e Integrações
n8n, webhooks, regex.

## Fundamentos de Ciência da Computação
Estruturas de dados (listas, filas, pilhas, árvores, grafos), algoritmos,
complexidade computacional.

## Matemática e Estatística
Álgebra linear, cálculo, probabilidade, estatística, distribuições
estatísticas, teste de hipóteses, intervalo de confiança, correlação e
causalidade, otimização, A/B testing.

## Engenharia de Software
Engenharia de software, clean code, orientação a objetos, design patterns,
testes unitários, Pytest, logging, observabilidade, documentação técnica,
arquitetura de sistemas de IA, sistemas distribuídos, escalabilidade.

## Segurança e IA Responsável
Segurança de APIs, autenticação, autorização, OAuth 2.0, JWT, gestão de secrets,
LGPD e privacidade de dados, AI security, prompt injection, data poisoning,
adversarial attacks, IA responsável (responsible AI), IA explicável (XAI),
SHAP, bias e fairness.

## Idiomas (falados)
Português (nativo), Inglês (intermediário/avançado).
