# All Projects — Full List

This is the complete list of every project in Pedro Campos' portfolio. When asked to list all projects, how many projects, or "which projects has Pedro done", use this full list. Projects: (1) RAG Customer-Service Assistants — production chatbots and virtual assistants with RAG and LLMs. (2) Portfolio AI Assistant — the RAG assistant on this site, grounded only in a curated knowledge base. (3) RAG Evaluation Pipeline — semantic search with measured quality: hybrid retrieval, reranking, CI-gated eval metrics. (4) SLM Fine-tuning Lab — a fine-tuned small language model vs. a frontier API, benchmarked on quality, latency and cost. (5) LLM Evaluation & Red Teaming (PT-BR) — a Brazilian-Portuguese safety and reliability benchmark for LLMs. (6) PT-BR LLM Benchmark — open, reproducible benchmark of LLMs in Portuguese covering hallucination, jailbreak and bias. (7) PT-BR Voice AI for Customer Service — fine-tuned ASR plus a RAG agent plus natural TTS voice pipeline. (8) Agent with Guardrails & Observability — an LLM agent modeled as an explicit state graph with cost guardrails and tracing. (9) Multimodal Agro Assistant — offline mobile app: weed segmentation with YOLO plus on-device LLM explanation in Portuguese. (10) AgroVision MLOps — the award-winning weed-segmentation research turned into a reproducible MLOps pipeline. (11) MLOps & Serving Platform — model registry, versioned canary/A-B deploys, drift monitoring and automatic rollback. (12) Edge Inference — the same segmentation model running in the field, offline, with ONNX/TensorRT and FP32/FP16/INT8. (13) Explainable Credit Scoring — end-to-end credit risk with calibration, SHAP explainability and a fairness audit. (14) Real-time Recommender System — a two-tower recommender served in milliseconds, judged by business metrics. (15) Streaming Anomaly Detection — real-time anomaly detection on an event stream with data-quality gates. (16) Deep Learning Research (Award-winning) — undergraduate research at UFV with award-winning publications. (17) Transformer from Scratch — attention, positional encoding and a BPE tokenizer implemented in pure PyTorch. (18) Financial-Market AI Solutions — AI solutions for the financial market, from prototype to delivery. (19) Open-source Product with Real Users — a public, usable tool with CI/CD and real adoption.
