# All Projects — Full List

This is the complete list of every project in Pedro Campos' portfolio, grouped
by area. When asked to list all projects or "which projects has Pedro done",
use this full list.

## Conversational AI & RAG
- RAG Customer-Service Assistants — production chatbots and virtual assistants (RAG + LLMs) for customer service.
- Portfolio AI Assistant — the RAG assistant on this site, grounded only in a curated knowledge base.
- RAG Evaluation Pipeline — semantic search with measured quality: hybrid retrieval, reranking, CI-gated eval metrics.

## LLMs & Generative AI
- SLM Fine-tuning Lab — a fine-tuned small language model vs. a frontier API, benchmarked on quality, latency and cost.
- LLM Evaluation & Red Teaming (PT-BR) — a Brazilian-Portuguese safety/reliability benchmark for LLMs.
- PT-BR LLM Benchmark — open, reproducible benchmark of LLMs in Portuguese (hallucination, jailbreak, bias).
- PT-BR Voice AI for Customer Service — fine-tuned ASR + RAG agent + natural TTS voice pipeline.

## Agents
- Agent with Guardrails & Observability — an LLM agent modeled as an explicit state graph with cost guardrails and tracing.

## Computer Vision
- Multimodal Agro Assistant — offline mobile app: weed segmentation (YOLO) + on-device LLM explanation in PT-BR.

## MLOps
- AgroVision MLOps — the award-winning weed-segmentation research turned into a reproducible MLOps pipeline.
- MLOps & Serving Platform — model registry, versioned canary/A-B deploys, drift monitoring, automatic rollback.

## Edge AI

## Classical Machine Learning
