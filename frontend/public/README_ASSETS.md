# Static assets to add

- `resume.pdf` — your real resume (linked from the header/hero "Download Resume").
- `og-image.png` — 1200x630 social preview image (used by Open Graph / Twitter cards).

Also replace `TODO_DOMAIN` in `index.html`, `robots.txt`, and `sitemap.xml`
with your deployed domain.
